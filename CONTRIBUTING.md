# Contributing

Thanks for helping improve Tomi Bp Edition.

## Before opening an issue

Please include:
- FlatCAM version (currently based on 8.994)
- operating system and architecture
- Python version
- steps to reproduce
- expected and actual behavior
- relevant console output or log excerpt
- a minimal sample file when it is safe and legal to share

Remove private PCB data, personal paths, credentials and machine-specific secrets.

## Pull requests

- Keep each pull request focused.
- Explain the user-visible effect and any compatibility impact.
- Update documentation when behavior changes.
- Include tests or reproducible manual test steps.
- Do not commit generated G-code, private PCB projects, virtual environments, caches or editor backups.
- Preserve upstream copyright and license notices.
