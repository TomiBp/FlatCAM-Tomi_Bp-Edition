# Security policy

This is a legacy desktop application that processes user-supplied CAD/CAM files and generates CNC output.

## Reporting a vulnerability

Please do not publish exploit details or private files in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub repository profile, if one is configured.

## Scope

Reports involving unsafe parsing of untrusted project files, arbitrary code execution, dependency vulnerabilities, or unintended disclosure of local files are relevant.

Do not include passwords, access tokens, private PCB layouts or personal data in reports.
